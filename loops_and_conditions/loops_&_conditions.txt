## 💡 KEY CONCEPTS AT A GLANCE

### Conditional Statements (Make Decisions)
```python
if condition:
    # One decision
    
if condition:
elif condition:
    # Multiple decisions
    
if condition:
else:
    # Two options
```

### Loop Statements (Repeat Code)
```python
for i in range(10):      # Repeat 10 times
    
for item in list:        # For each item
    
while condition:         # Repeat while condition is TRUE
```

### Loop Control (Control Repetition)
```python
break       # Exit loop immediately
continue    # Skip current iteration, go to next
pass        # Do nothing (placeholder)
```
