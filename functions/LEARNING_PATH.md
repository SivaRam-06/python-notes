## ✅ Practice Exercises

After learning each concept, try these:

**Function Basics:**
- Create a function that calculates area of a circle
- Create a function that checks if a number is prime

**Parameters:**
- Make a function with 5 parameters (mix required and optional)
- Create a function using *args to sum any number of values

**Return Values:**
- Create a function that returns 3 different values
- Create a function that returns dictionaries with formatted data

**Scope:**
- Create a global counter that functions can update
- Create nested functions with different scopes

**Types of Functions:**
- Identify which function type to use for different problems
- Create examples of each function type
- Compare pure vs impure functions

**Lambda:**
- Use lambda with sorted() on a list of dictionaries
- Use filter() with lambda to get specific items

**Recursion:**
- Write factorial function
- Write function to sum a list recursively

**Built-ins:**
- Use map(), filter() together
- Create complex data processing with built-ins
